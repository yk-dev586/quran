# Quran Electron — Offline Islamic Desktop App 2.1

تطبيق Electron محلي مبني بـ HTML + CSS + Vanilla JavaScript. هذه النسخة تعالج البحث والملاحظات والأحاديث، وتفصل إعدادات البرنامج عن حالة المستخدم، وتدعم لغة الواجهة من ملفات INI.

## التشغيل

```bash
npm install
npm start
```

يحتاج `npm install` إلى الإنترنت في أول مرة فقط لتنزيل Electron. محتوى التطبيق نفسه محلي، مع بقاء جلب مواقيت الصلاة ميزة تحتاج الإنترنت عند التحديث.

## الهيكل الجديد

```text
QuranElectronApp/
├─ config/
│  └─ settings.ini          # إعدادات البرنامج الأساسية
├─ locales/
│  ├─ ar.ini                # لغة الواجهة العربية
│  └─ en.ini                # لغة الواجهة الإنجليزية
├─ data/
│  ├─ quran.json
│  └─ hadith.json
├─ translations/            # ترجمات معاني القرآن بصيغة JSON
├─ audio/
│  └─ اسم القارئ/001.mp3 ...
├─ assets/fonts/
│  └─ myfont.ttf            # الخط الافتراضي المتوقع
├─ main.js
├─ preload.js
├─ index.html
└─ renderer/
   ├─ app.js
   └─ style.css
```

## البحث

البحث أصبح نافذة داخل التطبيق بدل `prompt/alert`. يدعم القرآن والأحاديث، مع تطبيع عربي للهمزات والتشكيل وبعض اختلافات الكتابة. نتائج القرآن قابلة للنقر وتفتح السورة والآية مباشرة.

## الأحاديث

البيانات تُطبع من مجموعة صيغ JSON شائعة، وليس فقط `{text: ...}`. التطبيق يتعرف على الحقول `text`, `matn`, `arabic`, `content`, `body` وغيرها، ويمكنه كذلك التعامل مع المصفوفات والكائنات المتداخلة. لكل حديث زر نسخ، مع البحث والحديث العشوائي.

## الملاحظات

زر الملاحظة يفتح نافذة داخل التطبيق، تعرض الآية كاملة، وتحفظ الملاحظة في حالة المستخدم. يمكن تعديلها أو حذفها، وتظهر في صفحة «المفضلة والملاحظات».

## الخط

الخط الافتراضي هو:

`assets/fonts/myfont.ttf`

تمت إضافة `@font-face` وتهيئة التطبيق لاستخدامه تلقائيًا عند وجوده. الملف نفسه غير مرفق في النسخة الحالية كما طلب المستخدم. يمكن وضعه مباشرة في المسار السابق، ثم إعادة تشغيل التطبيق.

## لغة الواجهة من INI

أضف أو عدّل ملفًا مثل:

`locales/ar.ini`

`locales/en.ini`

كل ملف يحتوي أقسامًا ومفاتيح، والواجهة تكتشف ملفات `.ini` تلقائيًا من مجلد `locales`. لتخصيص لغة جديدة انسخ أحد الملفات وأضف الترجمة ثم أعد تشغيل التطبيق.

## إعدادات البرنامج من INI

الملف:

`config/settings.ini`

يتحكم في القيم الافتراضية مثل اللغة، المظهر، الخط وحجم الخط وحدود نتائج البحث. أما تغييرات المستخدم اليومية مثل المفضلة والملاحظات وحجم الخط الحالي فتُحفظ في ملف حالة Electron داخل مجلد بيانات المستخدم.

## الصوت

تم تحسين اختيار ملف السورة بحيث يعتمد على رقم السورة الحقيقي ويدعم `001.mp3`, `01.mp3`, `1.mp3` وبعض الصيغ التي تحتوي الرقم داخل اسم الملف. كما أضيفت أداة «فحص ملفات التلاوة» التي تعرض عدد السور التي لديها ملف مطابق. إذا كان ملف صوتي نفسه خاطئ المحتوى فلن يستطيع البرنامج استنتاج محتوى الملف من الاسم وحده؛ يجب استبدال ملف الصوت الخاطئ بالملف الصحيح.

## مواقيت الصلاة

الواجهة الأصلية لمواقيت الصلاة بقيت موجودة، مع التخزين المحلي والتحديث عند الطلب، وتحديد الموقع بالإحداثيات أو المدينة.

## ملاحظات حول البيانات

هذه الحزمة لا تحتوي على نص القرآن أو ملفات صوتية أو الخط `myfont.ttf`. ضع بياناتك المحلية في المجلدات المناسبة ثم شغّل التطبيق.
